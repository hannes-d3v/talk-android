# Test-App: Audio-Wiedergabe (Talk QA)

Debug-Build des Branches `claude/admiring-hamilton-h19ffy` (Commit `63c8796`), QA-Variante mit der App-ID `com.nextcloud.talk2.qa` und der Version 25.1.0 Alpha 10. Sie installiert sich neben der normalen Talk-App.

Nur für Handys mit 64-Bit-ARM-Prozessor (arm64-v8a).

1. Auf dem Handy [`talk-qa-audio-arm64.apk`](talk-qa-audio-arm64.apk) öffnen und „Download“ (bzw. „View raw“) wählen.
2. Die heruntergeladene Datei öffnen und das Installieren aus dieser Quelle erlauben.
3. „Talk QA“ starten und mit dem Nextcloud-Konto anmelden.

Dieser Branch dient nur zum Herunterladen und kann danach gelöscht werden.
